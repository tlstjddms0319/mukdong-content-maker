# 실제 서비스 점검표

이 개발 환경에는 실제 AI 키·Instagram 계정·휴대폰이 없어서, 아래 항목은 **목업(가짜 응답)과 자동 테스트로만** 확인했습니다. Render에 배포한 뒤 한 번씩 직접 확인해 주세요. 키 값은 채팅에 붙여 넣지 말고 Render의 Environment에만 넣습니다.

## 1. 버튼 한 번으로 확인 (설정 → AI 연결 실제 점검)

`설정` 화면의 **AI 연결 점검하기**를 누르면 서버가 각 AI를 아주 작게 한 번씩 불러 봅니다. 키 값은 화면에 나오지 않습니다.

| 줄 | 정상이면 | 실패하면 확인할 것 |
|---|---|---|
| 문안 AI · Gemini | `정상 응답 (홍어)` | `GEMINI_API_KEY`, 무료 한도 초과(429)면 잠시 뒤 다시 |
| 문안 AI · Groq / Cloudflare | `정상 응답` | Gemini가 실패할 때 이어받는 예비 순서. 키가 없으면 건너뜀(정상) |
| 표지 점검 · Gemini 이미지 보기 | `견본 사진 점수 N/10 · 홍어로 보임` | "홍어로 안 보임"이면 `GEMINI_VISION_MODEL`을 더 큰 모델로 |
| 이미지 AI · Higgsfield | `키 인증 통과 (크레딧 사용 없음)` | 401/403이면 `HF_API_KEY_ID`·`HF_API_KEY_SECRET`이 한 쌍인지 |
| 이미지 AI · OpenAI | `키 인증 통과` | 401이면 `OPENAI_API_KEY` |
| 검색 트렌드 · 네이버 데이터랩 | `요즘 늘어난 말: 굴 +40%` 또는 `정상 응답` | 401/403이면 `NAVER_CLIENT_ID`·`NAVER_CLIENT_SECRET`, 예전 개발자센터 키면 `NAVER_API_STYLE=legacy` |
| 원격 누끼 · Higgsfield 배경 제거 | 꺼져 있으면 `건너뜀`(기본). 켜면 `키 있음 · 2026-10 사용 3/20 크레딧` | 호출 없이 키 유무와 이번 달 사용량 장부만 봅니다. `예산을 다 써서`면 그달은 무료 누끼로 그립니다. 설정에서 예산(0~200)을 늘릴 수 있어요 |

문안 AI는 자동 전환 때문에 첫 순서(Gemini)가 실패해도 화면에서는 티가 나지 않습니다. 이 점검에서 각각 따로 보입니다.

## 2. 직접 해 봐야 하는 것

새 화면 순서(무엇을 올릴까요 → 만들기 → 확인하고 올리기) 기준입니다.

- [ ] **사진 중심 · 사진 없이**: `만들기`에서 📷 사진 중심을 고르고 사진 없이 `만들기` → AI가 5장을 그려 약 10분 안에 `확인하고 올리기`까지 가는지, 그림이 음식답고 장마다 겹치지 않는지.
- [ ] **글 중심 · 사진 없이**: ✏️ 글 중심 → `만들기` → AI는 표지 한 장만 그리고 금방 끝나는지, 본문 장 글이 3줄 이내로 자연스러운지(어색하게 잘린 문장이 없는지).
- [ ] **사장님 사진으로**: 사진 3장을 올리고 두 갈래를 한 번씩 → 사진 중심은 장마다 사진 한 장, 글 중심은 표지에만 사진이 쓰이는지.
- [ ] **글(본문)**: 확인 화면의 글이 자연스럽고 # 태그가 붙는지. `글 다시 쓰기`로 새 글이 나오는지. 고친 글이 저장되는지(나갔다 와도 남는지).
- [ ] **이 장 다시 만들기**: AI가 그린 장에서 눌러 그 장만 바뀌는지.
- [ ] **멈췄을 때**: 만드는 도중 실패하면 쉬운 말 안내와 `다시 해 보기`가 나오고, 누르면 멈춘 장부터 이어 만드는지.
- [ ] **맨 뒤 홍보 포스터**: 게시물 맨 뒤에 포스터가 붙는지(카드에는 장 번호만 찍힘). `더보기 → 장 고치기`에서 끄면 마지막 장이 가게 명함 장으로 다시 그려지는지.
- [ ] **영구 저장소**: `설정 → 관리자용 설정 → 저장소 연결 확인`이 정상이고, Render에서 재배포(Manual Deploy)한 뒤에도 `내 게시물`이 남아 있는지.
- [ ] **메뉴가 다른 주제(과메기·미나리전·홍어찜)**: 과메기 주제로 한 번 만들어 그림에 삼합·수육이 끼어들지 않는지.
- [ ] **AI 사용량**: 하나 만든 뒤 `설정 → 관리자용 설정 → AI 사용량`이 늘었는지.
- [ ] **휴대폰**: 사장님 휴대폰(아이폰 사파리·안드로이드 크롬)으로 처음부터 `휴대폰에 저장하기`까지 한 번. 만드는 중에 다른 앱에 갔다 와도 진행 화면이 남는지.
- [ ] **Instagram 연결(사장님 연락 뒤)**: 테스터 수락 → 보안 확인 → **한 번만** 연결. 반복 재연결은 Meta 보안 확인(API access blocked)을 부릅니다. 연결 뒤 `인스타그램에 바로 올리기`로 한 번 게시.
- [ ] **원격 누끼(켰을 때만, 크레딧 사용)**: 예전 디자인으로 만든 게시물을 다시 그릴 때만 쓰입니다. 새 두 갈래 디자인은 쓰지 않습니다.

## 3. 결과 알려 주기

실패한 줄이 있으면 **줄 이름과 이유 문구**만 알려 주세요(키 값은 빼고). 예: `표지 점검 · 실패 — Gemini 429`.
