# 실제 서비스 점검표

이 개발 환경에는 실제 AI 키·Instagram 계정·휴대폰이 없어서, 아래 항목은 **목업(가짜 응답)과 자동 테스트로만** 확인했습니다. Render에 배포한 뒤 한 번씩 직접 확인해 주세요. 키 값은 채팅에 붙여 넣지 말고 Render의 Environment에만 넣습니다.

## 1. 버튼 한 번으로 확인 (설정 → AI 연결 실제 점검)

`설정` 화면의 **AI 연결 점검하기**를 누르면 서버가 각 AI를 아주 작게 한 번씩 불러 봅니다. 키 값은 화면에 나오지 않습니다.

| 줄 | 정상이면 | 실패하면 확인할 것 |
|---|---|---|
| 문안 AI · Gemini | `정상 응답 (홍어)` | `GEMINI_API_KEY`, 무료 한도 초과(429)면 잠시 뒤 다시 |
| 문안 AI · Groq / Cloudflare | `정상 응답` | Gemini가 실패할 때 이어받는 예비 순서. 키가 없으면 건너뜀(정상) |
| 표지 점검 · Gemini 이미지 보기 | `견본 사진 점수 N/10 · 홍어로 보임` | "홍어로 안 보임"이면 `GEMINI_VISION_MODEL`을 더 큰 모델로 |
| 이미지 AI · Higgsfield | `키 인증 통과 (크레딧 사용 없음)` | 401/403이면 `HF_API_KEY_ID`·`HF_API_KEY_SECRET`이 한 쌍인지 |
| 이미지 AI · OpenAI | `키 인증 통과` | 401이면 `OPENAI_API_KEY` |
| 검색 트렌드 · 네이버 데이터랩 | `요즘 늘어난 말: 굴 +40%` 또는 `정상 응답` | 401/403이면 `NAVER_CLIENT_ID`·`NAVER_CLIENT_SECRET`, 예전 개발자센터 키면 `NAVER_API_STYLE=legacy` |
| 원격 누끼 · Higgsfield 배경 제거 | 꺼져 있으면 `건너뜀`(기본). 켜면 `키 있음 · 2026-10 사용 3/20 크레딧` | 호출 없이 키 유무와 이번 달 사용량 장부만 봅니다. `예산을 다 써서`면 그달은 무료 누끼로 그립니다. 설정에서 예산(0~200)을 늘릴 수 있어요 |

문안 AI는 자동 전환 때문에 첫 순서(Gemini)가 실패해도 화면에서는 티가 나지 않습니다. 이 점검에서 각각 따로 보입니다.

## 2. 직접 해 봐야 하는 것

- [ ] **AI 구성안 다듬기**: 이미지 단계에서 `표지 후보 2장 만들기` → 장 제목·요점이 자연스러운지(어색한 문장, 과장, "누구나 좋아해요" 같은 표현이 없는지).
- [ ] **AI 표지 점검 배지**: 표지 후보에 `이미지 속 글자`, `홍어로 안 보임` 같은 배지가 사진과 맞게 붙는지. 점수가 높은 후보가 앞에 오는지.
- [ ] **영구 저장소**: `설정 → 저장소 연결 확인`이 정상이고, Render에서 재배포(Manual Deploy)한 뒤에도 `내 초안`이 남아 있는지.
- [ ] **원격 누끼(켰을 때만, 크레딧 사용)**: `설정 → 원격 누끼 사용`을 켜고, 배경이 복잡한 사진(식탁 위 여러 그릇) 한 장으로 컬러 블록 카드를 한 번 만들어 음식만 깔끔하게 오려졌는지. 배경 제거 주소는 개발 환경에서 확인하지 못했으니 **첫 호출 뒤 서버 로그에 `[cutout] 원격 누끼를 받지 못해` 경고가 있는지** 봐 주세요(있으면 `HF_REMOVE_BG_PATH`로 주소를 고칩니다). 같은 사진으로 다시 만들면 크레딧이 더 늘지 않아야 합니다(점검 줄의 사용량이 그대로).
- [ ] **메뉴가 다른 주제(과메기·미나리전·홍어찜)**: 과메기 주제로 AI 캐러셀을 한 번 만들어 모든 장 사진에 삼합·수육이 끼어들지 않는지. 끼어들면 그 장 화면을 보내 주세요.
- [ ] **맨 뒤 홍보 포스터**: 캐러셀 맨 뒤에 포스터가 붙고 장 번호가 포스터까지 세어 찍히는지(예: 5장이면 1/6~5/6). `장 고치기`에서 끄면 n/5로 다시 그려지는지. `설정 → 맨 뒤 홍보 포스터`에서 그림을 올리면 미리보기가 바뀌고 새로 만든 캐러셀 맨 뒤에 들어가는지, 서버를 다시 켠 뒤에도 남는지, `기본 포스터로 되돌리기`로 원래대로 돌아오는지.
- [ ] **AI 사용량**: 캐러셀을 하나 만든 뒤 `설정 → AI 사용량`의 오늘 사용량이 늘었는지. Groq를 쓴 날에는 남은 요청 수가 보이는지.
- [ ] **구성안 기본 문안 안내**: "기본 문안으로 채웠어요"가 뜨면 뒤에 붙은 이유와 Render 로그의 `[plan]` 줄을 함께 알려 주세요.
- [ ] **휴대폰 화면**: 사장님 휴대폰(아이폰 사파리·안드로이드 크롬)으로 주제 → 사진 3장 캐러셀 → 문안 → 최종 확인까지 한 번.
- [ ] **Instagram 연결(사장님 연락 뒤)**: 테스터 수락 → 보안 확인 → **한 번만** 연결. 반복 재연결은 Meta 보안 확인(API access blocked)을 부릅니다.

## 3. 결과 알려 주기

실패한 줄이 있으면 **줄 이름과 이유 문구**만 알려 주세요(키 값은 빼고). 예: `표지 점검 · 실패 — Gemini 429`.
