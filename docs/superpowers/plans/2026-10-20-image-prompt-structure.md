# 이미지 품질 강화 — 구조화된 음식 사진 프롬프트 계획서

작성: 2026-10-20 · 상태: 0단계 구현·A/B 완료, 사장님 결정으로 5칸 구조를 기본으로 켬(설정에서 끌 수 있음). 1~3단계는 다음 · 참고 자료: 사장님이 보내 주신 홍어·과메기 캐러셀 프롬프트 패키지(5칸 템플릿, 5장 구성, 치트키 낱말, 일관성 팁)

> 유튜브(클로드코드 카드뉴스 자동화 영상)는 제목만 읽혔고, 네이버 블로그와 노션 페이지는 이 환경에서 본문이 열리지 않았습니다. 분석은 붙여 주신 본문(템플릿·예시·팁)을 기준으로 했고, 그 내용이 참고 자료의 핵심입니다.

## 1. 참고 자료가 하는 것 vs 지금 앱이 하는 것

| 참고 자료의 방식 | 지금 앱 (코드에서 확인) | 차이가 만드는 결과 |
|---|---|---|
| **프롬프트를 5칸으로 나눠 씀**: 주인공 음식 → 담음새·식기 → 분위기·조명 → 질감 디테일 → 촬영(4:5, 45도, 얕은 심도) | 지시문 하나에 한국어·영어가 섞여 한 줄로 이어짐(`openaiRequest.ts buildImagePrompt`). 금지 문장이 7개 이상("글자 금지" 2번, 젓가락 금지, 보라 연기 금지, 일식 소품 금지…) | 이미지 모델(Grok Image 2.0)은 **앞쪽의 긍정 묘사**를 가장 잘 따르고, 긴 금지 목록은 묘사를 밀어낸다. 지금은 금지가 맨 앞·맨 뒤를 차지함 |
| **영어 묘사 + 한국어 고유명사 병기**: `fermented skate ray (Hongeo)`, `boiled pork belly (Suyuk)`, `aged kimchi (Mugunji)`, `brass Makgeolli kettle` | 장면 설명(`visualPrompt`)은 Gemini가 **한국어**로 씀. 영어 묘사는 메뉴 겉모습(`menu.ts look`)과 홍어회 질감 한 줄뿐 | 과메기·막걸리·미나리전·묵은지·수육의 영어 묘사와 **식기 낱말**(대나무 소쿠리, 놋그릇, 옹기, 양은 주전자, 초고추장 종지)이 없어 모델이 서양식 접시·일식 소품으로 흔들림 |
| **장마다 촬영 문법이 정해져 있음**: ① 한 상 45도 썸네일 → ② 손·젓가락으로 한 입 조합 → ③ 초장 찍는 매크로 / 김 오르는 액션 → ④ 바로 위 항공샷 → ⑤ 술 따르는·잔 부딪치는 엔딩 | 역할(표지·detail·overview)별 힌트와 표지 후보 4구도(`CANDIDATE_VARIANTS`)는 있으나, **한 묶음 안에서 장마다 다른 촬영 문법을 배정하는 단계가 없음**. 젓가락 장면은 기본 금지 | 같은 접시가 거리만 바뀌어 반복되고, "손으로 쌈 싸기·초장 찍기·막걸리 따르기" 같은 **동작 장면**이 거의 안 나옴 |
| **시리즈 일관성**: 색감·식기·조명 문구를 모든 장에 고정, 구도·동작만 바꿈 | `styleAnchor`(전 장 공통: 색온도·그릇·테이블)와 표지 이어 가기 참고 이미지가 있음 — **이미 잘 돼 있는 부분** | 유지. 다만 공통 설정을 "색 팔레트·식기·테이블·조명" 네 칸으로 더 구조화하면 흔들림이 줄어듦 |
| **글 얹을 여백**: `clean space on top for text overlay` | 레이아웃별 `photoHint`와 칸 비율 지시(`framingDirection`)가 있음 | 글자 겹침 레이아웃(overlay)에서 위쪽 여백 요청이 명시적인지 확인 필요 |
| **4:5 세로, 45도, 얕은 심도** | 카드 출력은 1080×1350(4:5). Grok은 4:5를 받지 않아 3:4로 받음(`higgsfieldRequest.ts defaultRatio:3/4`) | 3:4를 4:5로 맞추며 위아래가 조금 잘림. 피사체를 가운데 80% 안에 두라는 지시가 없음 |
| **매장 대표 "한 상"**: 홍어삼합 + 과메기 반반 상차림 항공샷으로 "둘 다 전문점" 강조 | 마지막 "가게" 장은 "따뜻한 식탁 한 상 45도"(`slideRequest.ts`) 한 줄 | 겨울(11~2월)엔 홍어·과메기 한 상을 대표 장면으로 쓰면 피드가 풍성해짐 |
| 모션·카메라 무빙 낱말(`slow zoom in`) | 영상은 만들지 않음 | 지금은 해당 없음(릴스를 하게 되면 그때) |

**결론**: 참고 자료의 핵심은 "프롬프트를 짧고 구조화된 영어 묘사로, 금지보다 긍정 묘사를, 장마다 다른 촬영 문법을"입니다. 지금 앱은 사실 정확성(홍어 색·익힌 살·일식 소품 금지)은 잘 잡았지만, **묘사의 구조와 촬영 문법의 다양성**이 비어 있습니다.

## 2. 할 일 (우선순위 순)

### 0단계 — 프롬프트 구조 바꾸기 (1~2일, 효과 가장 큼)

1. **5칸 구조로 조립**: `buildImagePrompt`가 지금처럼 문장을 나열하지 않고 아래 순서의 영어 묶음으로 만든다.
   `[Main dish] → [Plating & tableware] → [Environment & mood] → [Texture details] → [Shot] → [Consistency: 공통 팔레트·식기·조명] → [Do not: 글자·얼굴·일식 소품 — 짧게 한 묶음]`
   - 한국어 장면 설명(`visualPrompt`)은 구성안 단계에서 **영어 5칸(JSON)**으로도 받는다. 구성안 AI(Gemini)가 장면을 쓸 때 `scene:{dish, plating, mood, texture, shot}`를 함께 내게 하고, 예전 구성안(한 줄 한국어)은 그대로 받아 지금 방식으로 조립한다.
   - 금지 문장은 맨 끝 한 묶음으로 합치고 글자 금지는 한 번만(지금 2번).
   - 사실 정확성 지시(홍어 색·익힌 살 질감·주인공 메뉴)는 **[Main dish]·[Texture] 칸 안**으로 옮긴다. 버리는 게 아니라 자리를 옮기는 것.
2. **메뉴별 낱말 은행**(`store/menu.ts`에 칸 추가): 메뉴마다 영어 묘사 / 함께 나오는 것 / 식기 / 질감 낱말.
   - 홍어회: `fermented skate ray (Hongeo)`, 수육 `boiled pork belly (Suyuk)`, 묵은지 `aged kimchi (Mugeunji)`, 초고추장 `chogochujang`, 검은 접시·놋그릇
   - 과메기: `semi-dried Pacific saury (Gwamegi)`, `glossy oily fillets`, 알배기 배추·김·물미역·쪽파·마늘, 대나무 소쿠리(`bamboo sokuri`), 초고추장 종지
   - 막걸리: `milky rice wine`, 양은 주전자(`dented yangeun kettle`), 사발 `sabal bowl`
   - 미나리전·김치전·홍어애탕·홍어찜·홍어라면도 같은 틀로.
   - 지금 `look`(영어)·`lookKo`는 그대로 두고, 담음새·식기·질감을 따로 두어 5칸에 바로 꽂는다.
3. **A/B 비교로 확인**: 이미 있는 `scripts/compare-photo-look.mjs`에 "옛 조립 vs 새 조립" 모드를 붙여 같은 장면 6개(홍어회·삼합·과메기·애탕·막걸리·미나리전)를 둘 다 만들어 나란히 저장한다. 사장님이 보고 고르는 게 기준이고, 보조로 표지 점검 점수(`coverCheck.ts scoreImages`)를 적는다. 비용: Higgsfield 12장.

### 1단계 — 장마다 촬영 문법 배정 (1일)

4. **촬영 문법 목록**(`images/shots.ts` 새 파일): `hero-45`(한 상 45도) / `hand-action`(손·젓가락으로 한 입 조합, 얼굴 없음) / `macro-dip`(초장 찍는 매크로, 소스 방울) / `steam-action`(김·보글거림) / `flatlay`(바로 위 상차림) / `pour-ending`(따르기·잔 부딪치기) / `plate-low`(낮은 눈높이 결 강조).
5. **배정 규칙**: 구성안이 나오면 장 역할에 맞춰 서로 다른 문법을 배정한다(표지 = hero-45, 이유 장 = hand-action·macro-dip·plate-low 가운데 겹치지 않게, 결론·가게 장 = flatlay 또는 pour-ending). 탕·라면 메뉴면 steam-action을 반드시 하나 넣는다. 배정 결과는 `[Shot]` 칸에 들어가고, 젓가락 금지 문장은 **hand-action이 아닌 장에만** 붙인다.
6. **다양성 검사**: 지금의 "장면이 서로 같음" 검사(`carousel.ts` scenes 비교)에 촬영 문법 중복 검사를 더한다(같은 문법 2장 이상이면 구성안 고치기).

### 2단계 — 비율·여백 (반나절)

7. Grok Image 2.0이 받는 비율 목록(`imageAspect.ts HIGGSFIELD_ASPECTS`)에는 **4:5가 없다**(확인: 9:16·2:3·3:4·1:1…). 지금처럼 3:4로 받아 4:5로 맞추되, `[Shot]` 칸에 "keep the subject inside the central 80% of the frame"을 넣어 위아래 잘림으로 접시가 잘리는 일을 줄인다. 2:3으로 받아 좌우를 자르는 쪽이 나은지 A/B에 한 쌍 넣어 본다.
8. 글자 겹침 레이아웃(overlay)의 `photoHint`에 `clean plain space in the upper third for text overlay`가 들어가는지 확인하고 없으면 넣는다.

### 3단계 — 매장 대표 한 상 (반나절)

9. 마지막 "가게" 장과 겨울 시즌 표지에 쓸 **대표 상차림 장면**을 준비한다: 홍어삼합 한 접시 + 과메기 소쿠리 + 양은 주전자 막걸리를 바로 위에서. 11~2월에는 가게 장 기본 장면으로, 그 밖에는 삼합 한 상으로.
10. 사진 보관함에 사장님 실제 매장 사진이 있으면 그 장은 참고 사진 모드(`referenceMode:"dish"`)를 먼저 쓴다 — 지금 이미 되는 기능이므로 기본값만 바꾼다.

## 3. 바꾸지 않을 것 (참고 자료보다 지금이 나은 부분)

- 홍어회 색(탁한 연보라빛 분홍, 흰 연골 결), 익힌 살은 결을 은은하게 — 참고 자료의 `translucent pink and orange`는 참치·연어처럼 나와 이미 한 번 실패한 표현(2026-10-11). 우리 묘사를 유지.
- 얼굴 없음, 글자 없음, 일식 소품 금지, 확인 안 된 사실(원산지·구성) 금지 — 유지하되 맨 끝 한 묶음으로.
- 전 장 공통 스타일(`styleAnchor`)과 표지 이어 가기 — 유지.

## 5. 위험

- 영어 묘사가 길어지면 Grok이 글자를 그려 넣는 버릇이 다시 나올 수 있다(2026-10-12 "우춘향희 사딩월"). 글자 금지는 줄이되 없애지 않고, 표지 점검(`coverCheck`)의 글자 검사를 그대로 둔다.
- 손·동작 장면은 손가락이 이상하게 나올 수 있다. hand-action은 "손은 프레임 가장자리, 손가락 일부만"으로 제한하고 실패하면 지금처럼 다시 그리기·글자 카드로 넘어간다.
- Gemini 할당량: 구성안 JSON에 `scene` 5칸이 늘어나 응답이 길어진다. 토큰은 장당 100자 정도라 한도에 큰 영향은 없다.

## 7. 0단계 결과 (2026-10-20)

같은 장면 4개(홍어회·과메기·삼합 한 입·홍어애탕)를 예전/새 조립으로 만들어 나란히 봄(`npm run compare:prompt`, `output/prompt-ab/all.jpg`).
- 담음새·식기·분위기: 4장면 모두 새 구조가 나음(과메기는 배추·김·물미역·마늘·고추·초장·양은 주전자까지, 애탕은 받침·놋수저).
- 홍어 살: 처음엔 새 구조가 갈색·돼지고기 블록처럼 나와, 질감 칸에 색(연보라, 화이트밸런스 중립, 갈색·참치·연어 금지)과 "얇은 조각, 두꺼운 블록 금지"를 넣고 다시 만들어 해결.
- 사장님 결정: 기본으로 켜기. 설정 "이미지 지시문 5칸 구조 사용"으로 끌 수 있고, 그림 화풍·참고 이미지 모드는 아직 예전 조립.

## 8. 1단계 구현 (2026-10-20, `images/shots.ts`)

- 촬영 문법 7가지: 한 상 45도 / 손으로 한 입(손가락만, 얼굴 없음) / 초장 찍는 매크로 / 김 오르는 액션 / 바로 위 항공샷 / 따르는 엔딩 / 낮은 눈높이 결.
- 배정은 장 번호로 정해진다(구성안을 바꾸지 않음): 표지 = 한 상 45도, 이유 장 = 손으로 한 입 → 매크로 → 낮은 눈높이 순환(탕·라면은 김 오르는 액션부터), 결론 = 항공샷, 가게·방문 장 = 따르는 엔딩. 구성안의 detail·overview 역할은 매크로·항공샷 그대로.
- 젓가락 금지 문장은 손으로 한 입 장면에서는 뺀다. 계획의 "촬영 문법 중복 검사"는 배정이 장 번호로 정해져 겹칠 수 없으므로 두지 않았다.

## 9. 카드 디자인 — 풀블리드(기본)·화이트 매거진 (2026-10-21)

사장님: "캐러셀 디자인이 못생겼다". 원인: 액자·폴라로이드·메뉴판 같은 틀이 사진을 가리고(35~60%), 갈색·겨자 판, "1/3" 점선·매 장 바닥글이 앱 화면처럼 보이고, 게시물마다 테마가 바뀌어 피드에 통일감이 없었다.
- `styles/fullBleed.ts`(사진 10·글 8, **새 게시물 기본**): 사진 100% + 아래 그늘 + 흰 명조 제목 + 원인 한 줄, 얇은 장 번호, 이유 진행 막대, 로고만. 글 중심 본문은 표지 그림(글자 없는 원본)을 흐려 깐 배경 — 화면이 `backdrop`으로 보내고 생성 라우트가 그리는 쪽에 넘긴다.
