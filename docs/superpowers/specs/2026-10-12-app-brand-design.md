# 앱 전체 디자인 다듬기: 가게 브랜드 강화

작성일: 2026-10-12

## 목적

묵동 콘텐츠 메이커 앱 화면을 묵동홍어마을 홈페이지(v0.21)와 같은 느낌으로 맞추고, 화면 전환과 누름 반응에 애니메이션을 넣는다. 주 사용자는 휴대폰으로 쓰는 50대 사장님이다. 그래서 읽기 쉬움과 큰 누름 영역을 지킨다.

**사용자가 정한 것**
- 범위: 앱 전체
- 방향: 가게 브랜드 강화
- 색: 홈페이지와 같게
- 글꼴: 제목만 붓글씨

**범위 밖**
- 인스타그램에 올라가는 카드 이미지 디자인(`src/features/images/**`)
- 다크 모드
- 화면 순서·기능. 메뉴 위치만 휴대폰에서 아래 탭으로 옮긴다.

## 2. 글꼴

- **붓글씨를 쓰는 곳**: 화면 큰 제목(`main h1`)과 상단 앱 이름. 나눔 붓글씨(`next/font/google`의 `Nanum_Brush_Script`)를 `--font-brush` 변수로 연결한다. 붓글씨는 글자가 작아 보이므로 1.3배 키운다.
- **그대로 두는 곳**: 본문·버튼·숫자는 지금 글꼴 스택을 그대로 쓴다.

## 3. 메뉴

**휴대폰 (≤760px)**
- 위쪽: 로고, 앱 이름(붓글씨), 로그아웃(작은 버튼)만 둔다.
- 아래쪽 고정 탭 5개(아이콘+이름): 만들기, 내 게시물, 성과, 설정, 더보기
  - 선택된 탭은 진갈색 알약 배경으로 표시하고, 선택이 바뀌면 미끄러지듯 옮겨 간다.
  - 탭 높이는 64px 이상이고 `env(safe-area-inset-bottom)`을 반영한다.
- 더보기를 누르면 아래에서 판(시트)이 올라온다. 안에는 한 달 계획·콘텐츠 자료·이미지 모음·도움말이 있고, 바깥이나 Esc를 누르면 닫힌다.
- 본문 아래에 탭 높이만큼 여백을 둔다. 로그인 만료 안내(`.session-expired`)는 탭 위로 올린다.

**컴퓨터**
- 왼쪽 메뉴를 진갈색 메뉴판으로 바꾼다. 글씨는 크림색이다.
- 선택된 메뉴는 감빛 왼쪽 막대와 옅은 배경으로 표시한다.
- 더보기는 지금처럼 펼치는 방식으로 둔다.

## 4. 공통 부품

- **버튼**: 주 버튼은 감빛, 보조 버튼은 크림 면에 선을 두르고, 위험 버튼은 `--danger` 글씨다. 누르면 `scale(.97)`로 눌리고, 마우스를 올리면 살짝 떠오른다.
- **카드**: 기존 카드 클래스(`.draft-card`, `.topic-card`, `.library-card`, `.connection-card`, `.channel`, `.stat-tile`, `.post-card` 등)는 `--surface` 면, `--shadow-1` 그림자, `--radius-lg` 모서리를 쓴다.
- **입력칸**: 면은 `--surface`다. 누르면 감빛 테두리와 옅은 감빛 링이 생긴다.
- **배지·알림**:
  - `.soft-badge`는 `--accent-soft` 면에 감빛 글씨다.
  - `.notice`는 아이콘이 있는 상자다. 정보는 크림 면, 주의는 옅은 붉은 면에 ⚠를 둔다.

## 5. 애니메이션

모두 `prefers-reduced-motion: reduce`면 끈다(시간 0, 지연 0, 그려지기 없이 최종 상태).

- **화면이 바뀔 때**: `src/app/template.tsx`가 내용을 감싼다. 내용이 아래에서 8px 떠오르며 나타난다(240ms, ease-out).
- **차례로 나타나기**: 목록 안 카드(`.topic-card`, `.draft-card`, `.stat-tile`, `.post-card`, `.library-card`)가 40ms 간격으로 나타난다. CSS `animation-delay`에 `--i`(순번)를 쓰고, 최대 8개까지만 늦춘다.
- **누름**: 버튼·탭·카드 링크가 `transform`으로 100ms 반응한다.
- **탭 선택 표시**: 진갈색 알약이 `transform`으로 이동한다(280ms).
- **성과 화면**
  - 숫자 칸의 값이 0부터 올라간다(700ms). 클라이언트 컴포넌트 `CountUp`이 맡고, 화면에 들어올 때 한 번만 돈다.
  - 그래프 선은 `stroke-dashoffset`으로 그려지고(900ms), 영역은 서서히 나타난다.
  - 막대는 `scaleX`로 차오른다(600ms).
- **추천 주제 선택**: '✓ 선택' 배지가 톡 튀어나온다(scale 0.6→1, 200ms).
- **더보기 판**: 아래에서 올라오고(220ms), 뒤 배경은 서서히 어두워진다.

## 6. 확인

- 화면 9개를 375px·1280px에서 확인한다(만들기, 내 게시물, 성과, 설정, 한 달 계획, 콘텐츠 자료, 이미지 모음, 도움말, 로그인). 가로 스크롤, 겹침, 탭에 가린 내용이 없어야 한다.
- 위 색 대비는 모두 4.5:1 이상이다(계산 확인 완료).
- 기존 단위 테스트를 모두 통과한다. 메뉴 구조 테스트(`WizardShell.test.tsx`)는 새 구조에 맞춰 고친다.
- '동작 줄이기'를 켜면 애니메이션이 없어야 한다(`emulateMedia` 또는 CSS 확인).
