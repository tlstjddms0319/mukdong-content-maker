# 무료 카드 편집 사용법

로컬 코드 반영일: 2026-09-27. 이미지 생성 API를 호출하지 않고 등록한 사진·글꼴·도형을 편집합니다. 이 기능의 이미지 생성 API 비용은 0원이며, 글 생성과 기존 서버 운영 비용까지 무료가 된다는 뜻은 아닙니다. 배포 여부는 별도입니다.

## 사용 순서

1. `새 초안`에서 질문형 주제를 고르고 `이미지 선택 → 무료 카드 편집`을 누릅니다.
2. 카드 제목을 다듬고 짧은 설명을 적습니다. 설명은 직접 확인한 내용으로 작성합니다. 주제 기획의 내부 메모를 자동으로 게시 이미지에 넣지는 않습니다.
3. `사진형`, `비교형`, `글자형` 중 고릅니다. 사진형·비교형 설명은 90자, 글자형 설명은 180자까지입니다. 사진이 없으면 글자형으로, 비교 사진이 한 장이면 사진형으로 만들며 화면에 실제 적용 형식을 안내합니다.
4. `카드 미리보기 만들기`를 누르고 글자와 사진 잘림을 확인합니다. `이 카드 추가`로 게시물에 모읍니다.
5. 제목·설명·형식을 바꿔 다음 장을 만듭니다. 최대 10장을 모을 수 있고 순서를 앞으로 옮기거나 제거할 수 있습니다. 같은 카드 미리보기를 반복 추가할 수는 없습니다.
6. `카드 N장 사용`을 누릅니다. 저장 완료 후 기존 `문안 만들기 → 최종 화면 보기 → 전체 묶음 받기`로 이어갑니다. 카드 목록을 만든 뒤 이 버튼을 누르기 전까지는 초안에 저장되지 않습니다.

## 사진 보관함

`보관함에 사진 등록하기`에서 사진 파일, 이름, 검색어, 사진 구분, 원본 출처를 적습니다. JPG·PNG·WebP를 12MB, 4천만 화소까지 지원합니다. 원본은 별도로 보존하고 카드용으로 줄인 이미지를 보관합니다.

검색어 예: `수육, 김치, 삼합`. 추천은 사진을 분석한 결과가 아니라 등록된 검색어와 카드 제목의 일치에 따릅니다. 관련도가 같으면 최근 편집에 사용하지 않은 사진을 우선합니다. 관련 사진이 없을 때 무관한 사진을 자동으로 넣지 않습니다. 원하는 사진을 직접 고를 수도 있습니다.

- 직접 촬영: 직접 찍은 사진.
- 자료 사진: 사용 가능한 외부 사진. 원본 페이지 등 출처를 적습니다.
- 설명용 일러스트: 직접 제작했거나 사용 가능한 그림.
- AI 연출 이미지: 다른 도구에서 만든 AI 이미지. 무료 편집에서도 이 분류는 유지됩니다.

분류와 사진 이름은 카드에 표시합니다. AI 소재를 사용한 카드는 저장·문안·내보내기에서도 AI 편집 이미지로 분류합니다. 일반 편집 카드는 `design`으로 저장하고 AI 이미지 고지를 자동으로 붙이지 않습니다. 출처 분류는 등록자의 입력이며, 사진 권리나 실제 촬영 여부를 자동 판별하지 않습니다.

보관함은 앱의 기존 저장소 설정을 사용합니다. 로컬에서는 `data/asset-library`, 기존 영구 저장소가 설정된 경우에는 해당 저장소를 사용합니다. 저장소 자체의 자료 보존 조건은 초안과 같습니다.

## 이번 구현 범위

사진 보관·검색어 추천·세 가지 편집 형식·한국어 글자 합성·여러 카드 선택·초안 저장·복원·ZIP 내보내기를 지원합니다. 새 계정 연결, 무료 사이트 자동 수집, 음식 사진 분석, 외부 AI 호출, 자동 게시는 추가하지 않았습니다. 제목이나 사진 선택을 바꾸면 이전 미리보기는 지워지고 다시 만들어야 합니다.

카드마다 제목과 짧은 설명을 편집합니다. 긴 본문에서 여러 장의 내용을 자동으로 나누는 기능은 포함하지 않습니다. 실제 홍어 사진은 사용자가 등록해야 하며, 홈페이지 일러스트를 실제 촬영 사진으로 가져오지 않았습니다.
