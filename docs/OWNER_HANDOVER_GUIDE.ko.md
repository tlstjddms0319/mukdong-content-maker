## 3. 인스타그램 게시물 만들기 (가장 자주 쓰는 기능)

### 3-1. 들어가기

1. 컴퓨터나 휴대폰에서 <https://mukdong-content-maker-0319.onrender.com/> 를 엽니다.
2. **관리자 암호**를 넣고 로그인합니다. 한 번 로그인하면 8시간 유지됩니다.
3. 오래 안 쓰다가 열면 **처음 화면이 뜨는 데 1분 정도** 걸릴 수 있습니다(무료 서버가 잠에서 깨는 시간). 고장이 아니니 잠시 기다려 주세요.

> 글씨가 작으면 화면 위 **`글씨 크게`** 버튼을 누르세요. 어두운 화면이 편하면 **다크 모드**도 있습니다.

### 3-2. 세 단계로 끝납니다

**1단계 · 무엇을 올릴까요**

- 앱이 계절·명절·네이버에서 요즘 많이 찾는 말을 보고 **추천 주제 3개**를 보여 줍니다. 마음에 드는 것을 누르고 `다음`.
- 마음에 드는 게 없으면 `다른 주제 보기`, 직접 쓰고 싶으면 `직접 쓰기` 칸에 적습니다.
- 찍어 둔 음식 사진이 있다면 위쪽 **`📷 사진으로 주제 정하기`**에 넣어 보세요. 사진 속 음식으로 주제를 추천해 줍니다.

**2단계 · 만들기**

1. 모양을 하나 고릅니다.
   - **📷 사진 중심**: 사진이 크게, 글은 짧게
   - **✏️ 글 중심**: 큰 글씨 세 줄, 사진은 첫 장에만
2. (선택) **사진 올리기**: 가게에서 찍은 사진을 올리면 그 사진으로 만듭니다. 전에 올린 사진은 `전에 올린 사진에서 고르기`로 다시 씁니다.
3. 큰 **`만들기`** 버튼을 누릅니다. 카드 4~9장 + 맨 뒤 가게 홍보 카드 + 올릴 글까지 **자동으로** 만들어집니다.
   - 사진이 있으면 1~2분, 사진 없이 AI 그림으로 만들면 3~10분 걸립니다.
   - 기다리는 동안 다른 메뉴에 다녀와도 계속 만들어집니다.
   - 사진이 모자란 장을 AI 그림으로 채우기 싫으면 **`내 사진만 쓰기`**를 고르세요(비용 없음).

**3단계 · 확인하고 올리기**

1. ◀ ▶ 로 장을 넘기며 확인합니다. **원산지·가격·효능처럼 틀리면 안 되는 내용이 없는지** 꼭 봐 주세요.
2. 마음에 안 드는 장은 그 장을 띄우고 **`N번 장 고치기`**에서 `그림` 또는 `글`을 고른 뒤 "음식을 더 크게", "더 짧게" 같은 버튼을 누르거나 원하는 걸 적습니다.
3. 아래 올릴 글은 바로 고칠 수 있습니다(저절로 저장). 전체를 새로 쓰려면 `글 다시 쓰기`.
4. 카드 모양이 질리면 **`모양 바꾸기`**로 다른 모양을 고를 수 있습니다.
5. 아래 큰 버튼 중 하나를 누릅니다.

| 버튼 | 하는 일 |
| --- | --- |
| **인스타그램에 바로 올리기** | 한 번 더 묻고 지금 올립니다 |
| **예약해서 올리기** | "오늘 저녁 6시", "내일 점심 12시" 등을 고르면 그 시각에 저절로 올라갑니다 |
| **휴대폰에 저장하기** | 사진을 저장하고 글을 복사합니다(인스타그램 앱에서 직접 올릴 때) |
| **보관함에 보관하기** | 지금은 안 올리고 따로 모아 둡니다 |

> **예약 후 글이나 사진을 고치면 예약이 풀립니다.** 고친 뒤에는 다시 `예약해서 올리기`를 눌러 주세요. 앱이 풀렸다고 알려 줍니다.

### 3-3. 알아 두면 편한 기능

- **내 게시물**: 만든 게시물을 다시 열고, `더보기`에서 복제·같은 주제로 새로 만들기·지우기를 합니다. 보관함에 넣지 않은 게시물은 30일이 지나면 자동으로 지워집니다.
- **한 달 계획** (`더보기 → 한 달 계획`): 한 달치 주제를 미리 짜 두고, 칸마다 `이 주제로 만들기`로 시작합니다.
- **사진 보관함** (`더보기 → 이미지 모음`): 올린 사진이 모여 있습니다. **홍어회 참고 사진** 칸에 매장 홍어회 사진을 올려 두면, AI가 홍어회를 그릴 때 그 사진처럼 색과 썬 모양을 따라 그립니다.
- **가게 이야기 메모** (`설정`): 가게의 확인된 이야기(개업 계기, 손질 방법, 단골 이야기 등)를 적어 두면 글이 더 가게답게 나옵니다. **비어 있으니 시간 날 때 꼭 채워 주세요.**

## 4. 블로그 글 만들기 (네이버 블로그)

네이버는 블로그 자동 올리기를 막아 두었기 때문에, **글은 자동으로 만들고 올리기만 사장님이 직접** 하십니다. 오히려 계정이 제재될 걱정이 없습니다.

1. 블로그 글 만들기 주소에 들어가 **생성 버튼**을 누릅니다. 오늘 날씨·절기·요즘 인기 검색어를 넣어 "손주가 묻고 할아버지가 답하는" 말투의 글이 만들어집니다.
2. **`전체 복사`**를 누릅니다.
3. 네이버 블로그 → 글쓰기 → 붙여넣기.
4. 글 속 `[사진]` 자리에 가게 사진을 넣고 **발행**.

> 글에 사실과 다른 내용(가격, 원산지 등)이 있으면 발행 전에 고쳐 주세요.

## 8. 성과 확인 (`성과` 메뉴)

인스타그램 앱의 **`성과`** 메뉴에서 세 채널의 숫자를 한 화면에 봅니다.

| 채널 | 보이는 숫자 | 모으는 방법 |
| --- | --- | --- |
| 인스타그램 | 팔로워, 도달, 조회, 프로필 방문, 게시물별 좋아요·저장·공유 | 하루 한 번 자동 |
| 홈페이지 | 방문자, 조회, 전화·길찾기 버튼 클릭, 어디서 왔는지 | 하루 한 번 자동 |
| 네이버 플레이스 | 플레이스 유입, 지도·검색 유입, 검색 키워드, 리뷰 | 월 1회 통계 화면을 보고 기록 |

**숫자 읽는 법**

- 위쪽 기간에서 `이번 달`, `지난 달`, `개설 이후`를 고를 수 있습니다. `지금 가져오기`를 누르면 바로 새로 가져옵니다.
- **빈칸(—)은 0이 아니라 "아직 못 가져옴"**입니다.
- 조회·유입은 "본 횟수"이고 실제 방문 손님 수와는 다릅니다. 손님께 "어떻게 알고 오셨어요?"라고 가끔 물어보시면 가장 정확합니다.
- 네이버 숫자는 달마다 **하루 평균**으로 비교합니다. (참고: 플레이스 하루 평균 유입 8월 말 12.4회 → 9월 14.8회 → 10월 초 23.6회)

## 9. 휴대폰 알림 켜기 (한 번만)

1. 휴대폰 **크롬**으로 인스타그램 앱 주소에 들어가 로그인합니다.
2. `설정` → `휴대폰 알림` → **`이 휴대폰으로 알림 받기`** → `허용`.
3. 시험 알림이 오면 끝입니다. (크롬 메뉴 ⋮ → **홈 화면에 추가**를 하면 앱처럼 열립니다.)

| 오는 알림 | 이럴 때 |
| --- | --- |
| 오늘은 인스타그램 올리는 날이에요 | 정한 요일(기본 화·금) 오전 |
| N일째 새 글이 없어요 | 한동안 게시물을 안 만들었을 때 |
| 인스타그램에 올라갔어요 / 올리기 실패 | 예약 게시 직후 |
| 인스타그램 연결이 곧 끊겨요 | 연결 만료 전 → `설정`에서 다시 연결 |

밤 10시 이후에는 보내지 않습니다.

## 10. 비용과 결제

- 홈페이지, 앱 서버, 문안 AI(글 쓰는 AI), 알림, 통계 수집은 **무료 서비스**로 만들었습니다.
- **비용이 드는 것은 AI 그림(이미지 생성 크레딧)**입니다. 3차 방문 때 예상 비용을 안내드리고, 사장님 명의 결제수단과 자동 결제를 등록했습니다.
- **비용을 아끼는 방법**
  - 가게에서 찍은 사진으로 만들면 그림 비용이 거의 들지 않습니다.
  - 2단계에서 **`내 사진만 쓰기`**를 고르면 AI 그림을 쓰지 않습니다.
  - 카드 **글자만 고치기는 무료**입니다. `이 장 다시 만들기`(그림)는 누를 때마다 비용이 듭니다.
- 이번 달 AI 사용량은 `설정 → 관리자용 설정 → AI 사용량`에서 볼 수 있습니다.

## 11. 계정·서비스 정리

비밀번호는 이 문서에 적지 않습니다. 비밀번호는 사장님이 따로 안전하게 보관하시고, 다른 사람에게는 비밀번호 대신 **초대·권한 위임**으로 접근을 주세요.

| 서비스 | 쓰는 곳 | 관리 |
| --- | --- | --- |
| 네이버 스마트플레이스 | 네이버 플레이스 정보·통계 | 사장님 계정 |
| 인스타그램 (가게 계정) | 게시물·팔로워 | 사장님 / 앱이 연결해 자동 게시 |
| 인스타그램 만들기 앱 로그인 | 앱 사용 | 관리자 암호(사장님 보관) |
| 이미지 생성 AI 결제 | AI 그림 | 사장님 명의 결제·자동 결제 |
| 구글 비즈니스 프로필 | 구글 지도 정보 | 소유권 인증 진행 중 |
| GitHub · Render · Supabase · Meta 개발자 앱 · 구글 애널리틱스 | 앱·홈페이지 코드, 서버, 저장소, 인스타 연결, 홈페이지 통계 | 현재 청년팀 계정 — 사업 종료 전 이전 또는 공동 관리 방법을 함께 정합니다 |

## 12. 문제가 생기면

| 이런 일이 생기면 | 이렇게 해 보세요 |
| --- | --- |
| 앱이 안 열리거나 아주 느려요 | 1분 정도 기다렸다가 새로고침하세요(무료 서버가 깨는 중). |
| 로그인이 안 돼요 | 암호를 다시 확인하세요. 여러 번 틀리면 잠시 잠기니 몇 분 뒤 다시 하세요. |
| "사진을 다 만들지 못했어요"가 떠요 | `다시 해 보기`를 누르세요. 만든 장은 그대로 두고 멈춘 곳부터 이어 합니다. 계속 안 되면 사진을 올려서 만드세요. |
| 추천 주제나 글이 늘 비슷해요 | `다른 주제 보기`나 `글 다시 쓰기`를 눌러 보세요. 무료 AI 사용량이 잠시 찼을 수 있습니다. |
| 카드에 틀린 글자가 있어요 | `N번 장 고치기 → 글`에서 고치세요(무료). |
| 예약했는데 안 올라갔어요 | `내 게시물`에서 상태를 보세요. 예약 시각이 6시간 넘게 지나면 자동으로 올리지 않으니 `인스타그램에 바로 올리기`를 누르세요. |
| "인스타그램 연결이 끊겼어요" | `설정 → 인스타그램 연결 → 다시 연결`을 누르고 모두 허용하세요. |
| 손님이 영업시간이 다르다고 해요 | 네이버 플레이스·홈페이지·구글 지도를 차례로 확인하고, 다른 곳이 있으면 고치거나 알려 주세요. |
