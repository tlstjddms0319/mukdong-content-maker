# 휴대폰 알림(웹 푸시)

사장님이 꾸준히 올리시도록 앱이 휴대폰으로 알림을 보냅니다. 사이트를 닫아 둬도 오고(안드로이드 크롬), 알림을 누르면 해당 화면이 열립니다. 외부 서비스 가입이나 비용은 없습니다.

## 켜는 법 (사장님 휴대폰에서 한 번)

1. 휴대폰 **크롬**으로 배포된 앱에 로그인 → **설정** → **휴대폰 알림** → **이 휴대폰으로 알림 받기** → **허용**.
2. 바로 시험 알림이 하나 옵니다. 안 오면 **시험 알림 보내기**를 눌러 봅니다.
3. (권장) 크롬 메뉴(⋮) → **홈 화면에 추가**. 앱처럼 열리고 알림도 더 안정적으로 옵니다.
4. 알림이 "막혀 있어요"로 나오면: 크롬 주소창 왼쪽 아이콘 → 권한 → 알림 → 허용.

## 보내는 알림

| 알림 | 언제 | 누르면 |
| --- | --- | --- |
| 오늘은 인스타그램 올리는 날이에요 | 고른 요일(기본 화·금) 또는 한 달 계획에 주제가 있는 날, 고른 시각(기본 오전 10시) 뒤. 그날 글을 이미 만들었거나 예약해 뒀으면 안 보냄 | 만들기(기획 주제가 있으면 한 달 계획) |
| N일째 새 글이 없어요 | 마지막 글을 만든 뒤 고른 날수(기본 5일)마다. 올리는 날 알림과 겹치는 날은 안 보냄 | 만들기 |
| 인스타그램에 올라갔어요 / 올리기 실패 | 예약 게시 점검 직후 | 내 게시물 |
| 예약 글이 안 올라갔어요 | 예약 시각이 6시간 넘게 지나 자동 게시하지 않은 글(최근 3일) | 내 게시물 |
| 인스타그램 연결이 곧 끊겨요 / 끊겼어요 | 연결 만료 3일 전부터(자동 갱신이 실패한 경우) | 설정 |

- 날마다 오는 알림은 밤 10시 이후에는 보내지 않습니다. 같은 알림은 한 번만 보냅니다(`notifications/state.json`의 `sent`).
- 점검: 서버 안 타이머 5분마다(`NOTIFICATION_INTERVAL_SECONDS`), 그리고 GitHub 예약 작업이 1시간마다 `/api/instagram/scheduler`를 부를 때. 무료 서버가 잠들어 있으면 최대 1시간쯤 늦게 올 수 있습니다.

## 서버 설정

- 따로 넣을 값은 없습니다. 웹 푸시 서명 키(VAPID)는 처음 쓸 때 만들어 저장소(`notifications/vapid.json`)에 둡니다.
- **Supabase(`SUPABASE_URL`·`SUPABASE_SECRET_KEY`)가 꼭 필요합니다.** 없으면 Render 재시작 때 `/tmp`가 지워져 키와 구독이 사라지고, 휴대폰에서 알림 받기를 다시 눌러야 합니다.
- 키를 직접 정하려면 `VAPID_PUBLIC_KEY`·`VAPID_PRIVATE_KEY`(`npx web-push generate-vapid-keys`)를 넣습니다. 키를 바꾸면 기존 구독은 모두 무효가 되니 다시 알림 받기를 눌러야 합니다.
- 연락처는 `VAPID_SUBJECT`(없으면 `AUTH_URL`)를 씁니다.
