# 전체 점검 결과와 개선 계획 (2026-10-07)

앱 전체를 세 영역으로 나눠 코드를 다시 읽고, 실제로 문제가 나는지 확인했습니다.
- 이미지: 사진, AI 생성, 카드 그리기
- 문안·주제 AI
- 화면, 운영, 안정성

찾은 문제는 46건입니다. "실제 손해"(잘못 게시됨, 돈 쓴 이미지 날아감, 틀린 사실이 글에 들어감)가 큰 것부터 단계별로 고칩니다.
- **확인 방법**: 각 항목은 코드 위치를 다시 열어 보고, 일부는 작은 테스트 스크립트로 재현해서 확인했습니다.
- **크기 표시**: 작음(한두 파일), 중간(여러 파일, 동작은 그대로), 큼(구조나 디자인이 바뀜 → 사장님 확인 후 진행).

## 다음 단계(크기가 커서 확인 후 진행)

- **장 번호 바꿀 때마다 모든 카드를 다시 그림**: 무료 서버에서 9장이면 몇 분 걸립니다. 서버에 "번호 없는 카드"를 저장해 번호만 다시 찍거나, 카드에서 "n / N" 표시를 빼는 방법이 있습니다. 앞쪽은 구조가 커지고 뒤쪽은 디자인이 바뀌어서 사장님 선택이 필요합니다.
- **무료 카드 편집 상태 유지**: 이미지 단계를 나가면 무료 카드가 사라집니다. 다른 모드처럼 저장소로 옮기려면 그 화면을 다시 짜야 합니다.
- **올린 원본 사진 정리**: 사진+AI에서 올린 원본(최대 12MB)을 아무도 다시 읽지 않습니다. 저장하지 않게 바꾸려면 사진 처리 흐름을 바꿔야 해서, 25번 이후 사용량을 보고 정합니다.
