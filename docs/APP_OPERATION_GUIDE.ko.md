## 이 앱으로 할 수 있는 일

묵동홍어마을 인스타그램 게시물의 **주제 → 이미지 → 문안 → 최종 확인**을 한 화면에서 진행합니다. 완성한 초안은 다시 열고, 이미지와 문안을 파일로 내려받을 수 있습니다. Instagram 계정과 게시 서버가 별도로 연결된 경우에만, 사용자가 마지막 승인 버튼을 눌러 즉시 게시할 수 있습니다.

공개 주소: <https://mukdong-content-maker-0319.onrender.com/>

### 먼저 알아둘 점

- 로그인 암호는 앱 관리자가 설정한 암호입니다. OpenAI·Gemini·Supabase 계정 암호와 다릅니다. 로그인 상태는 최초 로그인부터 최대 8시간 유지됩니다.
- 주제와 문안은 설정한 문안 AI(기본: Gemini → Groq → Cloudflare 자동)를 시도하고, 모두 실패하면 앱에 들어 있는 기본 추천·문안을 사용합니다. **실시간 인기 검색어나 Instagram 트렌드를 가져오지는 않습니다.**
- AI 이미지는 Cloudflare 또는 OpenAI API를 호출합니다. 계정 요금제·사용량에 따라 비용이 생길 수 있고, 이미지 생성은 실패할 수도 있습니다. 실제 음식·가게와 다른 그림이 나올 수 있으므로 게시 전 반드시 확인하세요.
- 게시 희망일시는 **메모와 달력 표시용**입니다. 예약 실행·알림·자동 게시는 아직 없습니다.
- 현재 배포 서버의 영구 저장소 연결은 확인되지 않았습니다. 연결 전에는 Render 무료 서버 재시작·재배포 시 초안이 사라질 수 있으므로, 중요한 결과는 ZIP으로 내려받아 보관하세요.

## 사용자 사용법: 처음부터 완성까지

1. 공개 주소에 접속해 관리자 암호로 로그인합니다. 암호 입력란이 없다면 서버에 로그인 설정이 빠진 것이므로 관리자 설정이 필요합니다.
2. **1 주제**에서 추천 3개 중 하나를 누르거나 아래 입력칸에 직접 주제를 적습니다. `AI 추천 새로고침`을 누르면 다른 방향의 추천을 요청합니다. 원하는 주제를 정한 뒤 `이미지 선택`을 누릅니다.
3. **2 이미지**에서 아래 세 방법 중 하나를 고릅니다.
   - `실제 사진 사용`: JPG·PNG·WebP 사진 한 장을 선택합니다(최대 12MB). 업로드한 원본은 별도로 보존하고, 선택한 사진으로 초안을 만듭니다. **이 방식은 현재 한 장짜리 게시물**입니다.
   - `AI 이미지 생성`: `표지 후보 2장 만들기` → 마음에 드는 표지 선택 → `이 표지로 N장 완성하기` → 슬라이드 확인 → `이 캐러셀 사용` 순서로 진행합니다. 기본 N은 5장입니다.
   - `사진 + AI 함께`: 먼저 참고 사진을 고른 다음 같은 순서로 AI 캐러셀을 만듭니다. 참고 사진은 생성의 재료이고, 최종 선택 이미지는 AI가 만든 슬라이드입니다.
4. 이미지 저장 메시지가 나온 뒤 `문안 만들기`를 누릅니다. 저장에 실패하면 `저장 다시 시도`를 누르세요. 이미지가 저장되기 전에는 다음 단계로 갈 수 없습니다.
5. **3 문안**에서 생성된 글을 읽고 직접 고칩니다. 첫 문장·가게 연결·마무리·해시태그 재생성 버튼도 있습니다. 실제 가격, 영업시간, 메뉴 구성, 효능처럼 확인이 필요한 내용은 사람이 검토하세요. `최종 화면 보기`를 누르면 **현재 문안이 저장**되고 다음 단계로 이동합니다.
6. **4 확인**에서 이미지 순서와 문안을 검토합니다. `표지 이미지 받기`, `문안 복사`, `전체 묶음 받기`를 사용할 수 있습니다. ZIP에는 이미지 슬라이드, `caption.txt`, `metadata.json`이 들어갑니다.
7. Instagram 계정과 게시 서버가 연결되어 있다면, 화면의 계정·이미지 수·문안을 다시 확인하고 **`승인하고 Instagram에 게시`**를 눌러야 실제 게시 요청이 시작됩니다. 다운로드나 게시 희망일시 저장만으로는 게시되지 않습니다.

상단 단계 표시와 `이전` 버튼으로 앞 단계에 돌아갈 수 있습니다. 다음 단계는 필요한 주제·이미지·문안이 준비되어야 열립니다. **주제를 바꾸면 새 초안이 시작되어 이전 이미지·문안 선택은 현재 작업에서 해제**되므로, 기존 결과는 `내 초안`에서 다시 여세요.

### 저장한 초안을 다시 쓰려면

왼쪽 `내 초안`에서 원하는 카드의 `다시 열기`를 누릅니다. 이미지까지만 저장한 초안은 이미지 단계부터, 문안까지 저장한 초안은 확인 화면부터 이어집니다. 새 게시물을 만들려면 `새 초안 만들기`를 누르세요. 브라우저는 최근 작업의 **초안 번호만** 기억하며, 실제 내용은 서버 저장소에서 불러옵니다.

`내 초안`에서는 한국시간 기준 `게시 희망일시`와 `최종 확인 완료`도 저장할 수 있습니다. 이미지와 문안이 있어야 최종 확인에 체크할 수 있고, 이미지·문안을 고치면 확인 표시는 해제됩니다. 날짜가 지나도 자동 게시되지 않습니다.

### 한 달 기획 · 복제 · 성과 기록

- **한 달 기획에서 시작하기**: `내 초안` 맨 위 `한 달 콘텐츠 기획`의 칸에서 `이 주제로 초안 시작`을 누르면 그 게시일과 추천 디자인 계열이 함께 넘어갑니다. 처음 저장할 때 그날 한국시간 18:00이 게시 희망일시로 채워집니다(지난 날짜는 비워 둡니다). 기획표에는 칸마다 `기획 / 이미지 저장됨 / 문안까지 완료 / 최종 확인 완료 / 날짜 지남`이 표시되고, 진행 중인 칸은 `이어서 만들기`로 바로 열립니다.
- **복제해서 고치기**: 사진·문안을 그대로 가진 새 초안을 만들어 엽니다. 게시 희망일시·최종 확인·기획 연결·성과 기록은 복제하지 않습니다. `같은 주제로 새로`는 주제와 설명만 이어받아 처음부터 시작합니다.
- **성과 기록**: 게시하고 2~3일 뒤 Instagram 인사이트의 좋아요·댓글·저장·공유(·도달)를 초안 카드의 `성과 기록`에 적습니다. `성과 돌아보기`가 반응 점수(좋아요 + 댓글×2 + 저장×3 + 공유×3) 순위와 디자인 계열·독자 유형·요일별 평균을 보여 주고, 평균보다 반응이 좋았던 주제(기록 2개 이상일 때)는 다음 주제 추천 AI에 참고로 넘어갑니다.

## 앱 내부에서 실제로 일어나는 일

| 사용자의 행동 | 앱의 처리 | 저장 시점 |
| --- | --- | --- |
| 주제 화면 열기·새로고침 | 서버가 Gemini에 주제 3개를 요청합니다. 실패하면 앱에 미리 준비된 주제를 순환해 보여줍니다. | 주제만 고를 때는 아직 초안 파일이 만들어지지 않습니다. |
| 직접 사진 고르기 | 파일 형식과 12MB 제한을 검사하고 원본을 보관합니다. 선택 이미지를 초안에 기록합니다. | 업로드 후 초안 저장 요청이 성공하면 저장됩니다. |
| AI 이미지 만들기 | Gemini에 캐러셀 구성을 요청하고, Cloudflare 이미지 AI를 우선 호출합니다. 자동 모드에서 Cloudflare가 실패하면 OpenAI로 전환할 수 있습니다. 표지 2장 중 1장을 고른 뒤 나머지 슬라이드를 순서대로 생성합니다. | `이 캐러셀 사용`을 눌러 초안 저장 요청이 성공하면 저장됩니다. |
| 문안 화면 열기 | Gemini에 문안을 요청합니다. 실패하면 기본 문안을 표시합니다. 사용자가 직접 수정할 수 있습니다. | `최종 화면 보기`를 눌러 저장 요청이 성공해야 확정됩니다. |
| 전체 묶음 받기 | 브라우저에서 선택한 이미지와 문안으로 ZIP을 만들어 다운로드합니다. | PC에 다운로드한 파일은 서버 초안과 별도로 보관됩니다. |
| 게시 희망일시 저장 | 초안에 한국시간의 희망일시와 확인 상태를 기록하고 `내 초안` 달력에 표시합니다. | `예약 준비 저장` 버튼을 누르면 저장됩니다. 게시 작업은 실행하지 않습니다. |
| Instagram 게시 승인 | 연결된 Meta 계정과 초안·이미지·문안을 검사한 뒤, Meta에 게시 요청을 보냅니다. 중복 게시 방지용 상태를 기록합니다. | `승인하고 Instagram에 게시`를 직접 눌렀을 때만 요청합니다. |

기본 설정은 **5장 캐러셀, 실제 사진 우선 안내, 4:5 표시, Gemini 문안, Cloudflare 우선 이미지 AI**입니다. AI 방식에서 5장을 완성하려면 표지 후보 2장과 나머지 4장, 즉 보통 **이미지 생성 6장분**을 요청합니다. 후보를 다시 만들면 요청량과 비용이 더 늘 수 있습니다.

## 저장·배포·비용의 현재 상태

- 로컬 실행에서는 기본적으로 프로젝트의 `data/` 폴더에 초안·설정·업로드 원본을 저장합니다.
- Render 무료 배포의 기본 저장 위치는 임시 `/tmp/mukdong-content-maker`입니다. **재시작·재배포 후 자료 유지가 보장되지 않습니다.** 브라우저에 초안 번호가 남아 있어도 서버의 초안이 사라지면 복원할 수 없습니다.
- 영구 보관 기능의 코드는 준비되어 있습니다. Supabase에 **비공개** `mukdong-private` 버킷을 만들고 Render 서버 환경변수 `SUPABASE_URL`, `SUPABASE_SECRET_KEY`를 **둘 다** 등록해야 새 초안·설정·업로드 원본을 거기에 저장합니다. 둘 중 하나만 설정하면 오류가 나며, 이전 임시 자료는 자동 이동하지 않습니다. 현재 실제 연결·복구 시험은 완료된 것으로 확인되지 않았습니다.
- Instagram 연결 정보와 게시 기록도 Supabase가 설정돼 있으면 같은 버킷(`instagram/…`)에 저장됩니다. 설정하지 않으면 Render 무료 서버가 잠들었다 깨어날 때(약 15분 미사용 후)마다 연결이 풀립니다.
- Gemini·Cloudflare·OpenAI는 앱 구독료와 별개인 **각 서비스의 API 사용량·요금 정책**을 따릅니다. AI 키 유무는 `설정` 화면에서 확인할 수 있지만, 키 값을 그 화면에서 입력·수정하는 기능은 없습니다. 키는 서버 환경변수로 관리합니다.
- 이 파일은 **소스코드와 마지막으로 확인된 설정**을 설명합니다. 현재 배포 계정의 외부 서비스 로그인·잔액·실제 API 성공 여부는 이 문서만으로 판정할 수 없습니다.

## `설정` 화면에서 실제로 바뀌는 것

| 항목 | 현재 동작 |
| --- | --- |
| 캐러셀 장수 | 실제 AI 캐러셀 생성 수에 반영됩니다: 3·5·7·10장. 직접 사진 모드는 여전히 한 장입니다. |
| 이미지 AI | `자동`은 Cloudflare 우선·실패 시 OpenAI 대체, `Cloudflare만`과 `OpenAI만`은 지정 서비스만 시도합니다. 해당 API 키가 있어야 합니다. |
| 문안 AI | 자동은 키가 있는 순서로 Gemini, Groq, Cloudflare를 시도합니다. 하나만 고르면 그 서비스만 씁니다. |
| 이미지 제작 방식·비율·후보 수·문안 길이·안전 체크 항목 | 설정값은 저장되지만 **현재 제작 화면의 실제 동작에는 연결되지 않았습니다.** 예를 들어 후보 수 설정과 관계없이 표지는 2장을 만듭니다. |
| 말투 버튼 | 화면에는 보이지만 현재 문안 생성 요청을 바꾸는 동작은 연결되지 않았습니다. 원하는 말투는 문안을 직접 고쳐 적용하세요. |
| 인기 주제 연결 | `향후 제공` 표시만 있으며 실시간 인기 데이터 수집은 아직 없습니다. |

`설정`의 Instagram 연결 버튼은 Meta 앱 정보와 프로페셔널 계정이 준비되어 있어야 작동합니다. 연결되지 않은 상태에서는 초안 제작·다운로드를 먼저 사용하세요.

## 막힐 때 확인할 것

- **AI가 실제로 되는지 모르겠어요:** `설정 → AI 연결 실제 점검`의 `AI 연결 점검하기`를 누르면 문안 AI·표지 점검·이미지 AI 키를 하나씩 실제로 불러 결과를 보여 줍니다. 배포 뒤 직접 확인할 항목은 [실제 서비스 점검표](LIVE_CHECKLIST.ko.md)에 모아 두었습니다.
- **추천이나 문안이 늘 비슷해요:** 문안 AI 호출이 실패해 준비된 내용으로 대체되었을 수 있습니다. 주제 화면에는 `AI 추천을 불러오지 못해 준비된 주제를 보여드려요` 안내가, 문안 화면에는 `문안 생성이 완료되지 않았어요` 표시가 나타납니다. 정상일 때는 `AI로 문안을 만들었어요 (Gemini)`처럼 어느 서비스가 썼는지 보입니다. 잠시 후 `AI 추천 새로고침`이나 `전체 문안 새로 생성`을 다시 눌러 보세요.
- **AI 이미지가 생성되지 않아요:** `설정`에서 이미지 AI 연결 상태를 확인하거나 직접 사진을 사용하세요. `자동`은 OpenAI로 대체되어 비용이 발생할 수 있습니다.
- **초안이 안 보여요:** 먼저 같은 앱 계정으로 로그인했는지 확인하세요. Render 재시작 후 임시 저장 자료가 사라졌다면 영구 저장 연결 전의 초안은 복구되지 않을 수 있습니다. 내려받은 ZIP이 있으면 그 파일을 보관하세요.
- **Instagram에 게시할 수 없어요:** `설정 → Instagram 연결`에서 계정 연결과 게시 서버 설정을 확인하세요. 프로페셔널 계정, Meta 앱 권한, 공개 HTTPS 이미지 주소가 필요합니다. 설정 항목이 채워졌다는 표시만으로 실제 게시 성공이 검증된 것은 아닙니다.
- **도움말·이미지 제작실·콘텐츠 자료가 안 열려요:** 현재 메뉴 링크만 있고 해당 독립 화면은 구현되지 않았습니다. 이미지 제작은 `새 초안`의 2단계에서 사용하세요.

## 현재 범위와 다음 과제

현재 구현된 범위는 **초안 제작·수정·다운로드·희망일시 기록**이며, 조건을 갖춘 경우에 한해 **명시적 승인 후 즉시 Instagram 게시**를 요청하는 코드가 있습니다. 다음 운영 과제는 Supabase 영구 저장소의 실제 연결·복구 시험, Instagram 연결/게시 기록의 영구화, Meta 실계정 게시 검증입니다. **여러 장의 실제 사진으로 만드는 캐러셀**(이미지 단계의 `실제 사진 사용`, 최대 10장, 사진 보관함 저장)과 **계절·명절 시기를 반영한 주제 추천**이 추가됐습니다. **실시간 검색 트렌드 연결**은 아직 없습니다.
