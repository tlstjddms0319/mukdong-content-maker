# 성과 모으기 설정 안내

앱의 **성과** 메뉴는 우리가 처음 만든 세 채널의 숫자를 한곳에 모읍니다.

| 채널 | 가져오는 방법 | 처음 한 번 할 일 |
|---|---|---|
| 인스타그램 | 앱이 하루 한 번 자동으로 가져옴 | 인스타그램 다시 연결 |
| 홈페이지(GA4) | 앱이 하루 한 번 자동으로 가져옴 | 서비스 계정을 GA4 뷰어로 추가 |
| 네이버 플레이스·블로그 | Claude가 통계 화면을 읽어 기록 | 앱 안 브라우저에서 네이버 로그인 |

성과 화면의 **지금 가져오기**를 누르면 하루를 기다리지 않고 바로 가져옵니다. **CSV 내려받기**는 보고서용 표입니다(엑셀에서 열림).

## 1. 인스타그램 다시 연결

인사이트(팔로워·도달·조회·프로필 방문)를 읽으려면 권한 `instagram_business_manage_insights`가 더 필요합니다.

1. Meta 개발자 앱 → Instagram → API 설정(Instagram 로그인 비즈니스)에서 권한 목록에 `instagram_business_manage_insights`가 켜져 있는지 확인합니다. 가게 계정이 이 앱의 테스터·관리자 역할이면 앱 심사가 필요 없습니다.
2. 앱 배포 뒤 **설정**을 엽니다. 인스타그램 칸에 "다시 연결" 버튼이 보이면 누르고, 권한 화면에서 모두 허용합니다.
3. **성과 → 지금 가져오기**를 눌러 팔로워 수가 나오는지 확인합니다.

성과 화면의 **게시물별 현황**에는 계정에 올린 최근 50개 게시물(인스타그램 앱에서 직접 올린 것 포함)의 조회·도달·좋아요·댓글·저장·공유가 하루 한 번 새로 채워집니다. 최신순·조회·좋아요·저장 순으로 바꿔 볼 수 있고, 누르면 인스타그램의 그 게시물이 열립니다. CSV에도 게시물별 줄이 들어갑니다.

앱으로 올린 게시물의 좋아요·댓글·저장·공유·도달도 '성과 기록'에 자동으로 채워집니다. 올린 뒤 7일은 날마다, 90일까지는 일주일마다 새로 가져옵니다. 직접 적은 성과는 덮어쓰지 않습니다.

## 2. 구글 애널리틱스(GA4) 연결

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에서 프로젝트를 하나 고르거나 만듭니다.
2. **API 및 서비스 → 라이브러리**에서 `Google Analytics Data API`를 찾아 **사용**을 누릅니다.
3. **IAM 및 관리자 → 서비스 계정 → 서비스 계정 만들기**. 이름은 `mukdong-metrics`처럼 정하고, 역할은 주지 않아도 됩니다.
4. 만든 서비스 계정 → **키 → 키 추가 → 새 키 만들기 → JSON**. JSON 파일이 내려받아집니다. 이 파일은 비밀번호와 같으니 다른 곳에 올리지 않습니다.
5. [GA4](https://analytics.google.com/) → **관리 → 속성 액세스 관리 → +** → 서비스 계정 이메일(`…@….iam.gserviceaccount.com`)을 **뷰어**로 추가합니다.
6. Render → 서비스 → **Environment**에서 `GA4_SERVICE_ACCOUNT_JSON`에 JSON 파일 내용 전체를 붙여 넣고 저장합니다. `GA4_PROPERTY_ID`(555483214)와 `GA4_START_DATE`(2026-09-07)는 `render.yaml`에 이미 들어 있습니다.
7. 재배포가 끝나면 **성과 → 지금 가져오기**. 처음에는 시작일부터 어제까지를 한 번에 가져옵니다.

가져오는 값은 일별 방문자·방문·페이지 조회, 전화 버튼(`phone_click`)·길찾기 버튼(`directions_click`) 클릭, 유입 경로 상위 10개입니다. `naver / place`는 네이버 플레이스의 홈페이지 링크로 들어온 방문입니다(2026-10-06부터 표시).

## 3. 네이버 플레이스·블로그

네이버는 스마트플레이스·블로그 통계를 가져갈 공식 API가 없습니다. 그래서 Claude가 화면을 읽어 기록합니다.

1. Claude에게 "네이버 숫자 확인해 줘"라고 말합니다.
2. Claude가 앱 안 브라우저에서 스마트플레이스 통계를 엽니다. 로그인 화면이 나오면 **사장님이 직접** 로그인합니다(Claude는 비밀번호를 넣지 않습니다).
3. Claude가 리포트·플레이스 탭의 숫자를 읽어 **성과 → 네이버 기록 추가·고치기**로 저장합니다. 같은 기록 이름(예: `2026-10`)으로 저장하면 그 기록을 고칩니다.

직접 넣을 때도 같은 폼을 씁니다. 날짜가 다른 기록과 겹치면 저장되지 않습니다.

**비교 규칙.** 하루 평균은 *숫자가 있는 날*로 나눕니다. 한 달 환산은 그 하루 평균에 그달 일수를 곱합니다. 네이버 화면의 '일 평균'과 '지난 달 대비 %'는 달력 일수로 나눠서 일부만 있는 달(8/25부터 잡힌 8월, 진행 중인 달)을 작게 보이게 하므로 쓰지 않습니다.

키워드·채널·성별·연령은 네이버 화면의 비율 그대로 적습니다. 유입 수를 곱해 '키워드별 횟수'로 만들지 않습니다. 연령 비율은 성별 안에서의 비율이고, 화면의 '20~30대(어림)'는 성별 비율로 가중해 합친 값입니다.

## 숫자 읽는 법

- **팔로워**: 인스타그램은 팔로워의 일별 변화를 100명 이상일 때만 줍니다. 그래서 앱이 날마다 총 팔로워 수를 저장해 그래프를 만듭니다. 연결 전 날짜는 비어 있습니다.
- **도달·반응한 계정 합계**: 날마다의 값을 더한 것이라, 같은 사람이 여러 날 보면 여러 번 세어집니다.
- **빈칸(—)**은 아직 못 가져왔거나 인스타그램·GA4가 주지 않은 값입니다. 0이라는 뜻이 아닙니다.
- 서로 다른 서비스의 숫자를 더해 '고객 수'로 쓰지 않습니다. 온라인에서 본 횟수는 실제 방문·매출과 다릅니다.
